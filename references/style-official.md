# 央媒体 v3 写作口径（2026-11-24 定稿）

> 用户确认的最新口径。与 v1/v2 冲突时，**以本文件为准**。
> 目标：把「企业官网启用中文域名」这件事写成**人民网/新华网/中国日报网式的行业报道**，而不是企业介绍或广告。

## 1. 结构（固定四段式，其余自由）

| 段落 | 写什么 | 硬约束 |
|---|---|---|
| **第 1 段** | **政策 / 行业活动 / 行业分析切入**（不写企业） | 引用可核查的政策名称与年份，或行业量化数据；不出现企业名 |
| **第 2 段** | 一句话交代「某某公司官网启用中文域名“X.网址”」+ 一句**企业数字化需求** | 该段 ≤130 字、2 句；企业全称逐字出现；域名逐字出现；含「官网启用」四字 |
| **第 3 段起** | 行业分析：产业带、供应链、渠道、标准、监管、区域市场 | **不得再出现「中文域名 / .网址 / 域名 / 网址」任何字样**；「官网」也尽量不再出现 |
| **末段** | 宏观收束，一句判断 | 不喊口号、不号召注册 |

## 2. 标题规则（由提示词引导，不由脚本卡）

- **必须含**：企业名称（**优先全称，可去掉「有限公司／股份有限公司／科技／股份」这类通用后缀**，品牌字完整保留）
- **必须含**：「官网」「网站」「网址」三者之一（**只出现一种即可**，位置随意：开头／中间／结尾）
- **可以用行业内容填充**：政策、市场、品类、区域、趋势
- **禁止句式**：
  - `××官网启用中文域名“X.网址”`（最容易被判广告）
  - `××正式上线` / `××品牌升级完成` / `××重磅发布`
- 长度 ≤30 字（自媒体标题上限；由提示词自觉遵守，`draft_check` 的 H2a/H2b/H2c **只作参考，不作为拦截条件**）

## 3. 语气与素材

- **央媒体语气**：客观、克制、有政策依据；不吹捧、不用形容词堆砌
- 可引用的素材类型：
  - 国家政策（写明发布机关与年份，如「2024 年 3 月，市场监管总局等六部门印发……」）
  - 行业数据（写明口径与年份，如「据行业研究机构统计，2021 年……约 3140 亿元，同比增长 9.52%」）
  - 区域产业带事实（港口、集群、配套、物流半径）
- 检索工具：`anysearch_fill.py --industry "行业名"` / `--company "企业名"`
- **不写**：企业注册资本、经营范围、法定代表人、成立日期（均为禁用词）
- **不写**：任何「提升流量/成交/排名」的效果承诺；不虚构网站功能

## 4. 与旧口径的差异

| 维度 | v2（2026-11-23） | **v3（本文件）** |
|---|---|---|
| 第 1 段 | 企业业务介绍 | **政策/行业切入**（不写企业） |
| 域名位置 | 第 1 段 | **第 2 段，简短一句** |
| 域名段落长度 | ≥100 字 | ≤130 字、2 句 |
| 标题 | 企业简称 + 「官网」 | **企业全称（可去后缀）+ 官网/网站/网址之一**，可用行业内容填充，禁「启用中文域名」句式 |
| 后文 | 行业内容（隐含企业） | 行业内容（**完全不提企业也可**）|
| 标题门禁 | 脚本判定 | **提示词引导，脚本只提示不拦截** |

## 5. 门禁怎么跑

```powershell
python <FABU>\draft_check.py <稿件> --full "<企业全称>" --short "<去后缀全称>" --domain "<域名>.网址"
```

- **必须通过**：H1a/H1b/H1d/H1e（全称与域名逐字出现在第 1 或第 2 段）、H1c（含「官网启用」）、H1f（该段 ≥100 字且 ≥2 句）、H7（900–1150 字）、H5/H6（无禁用词）
- **只作参考**：H2a/H2b/H2c（标题相关）——按本文件的标题规则判断，不要为了过脚本把标题改回「启用中文域名」句式
- 科普稿仍按 `kepu_check.py` 执行，不受本文件影响
